Replay Samples

Dev tool: replays a session's exported sample CSV (the file from the site's "Export CSV" button, columns sessionId,sensor,t,recvAt,x,y,z,gx,gy,gz,vVert,phase,repIndex) through fresh copies of processing.js's tracker and reps.js's rep detector, ignoring the file's own stale vVert/phase/repIndex columns. Use this to check whether a threshold change actually fixes a real recording, instead of only testing against simulate.js's synthetic scenarios. Open this file directly (no server needed — it doesn't touch Web Bluetooth or IndexedDB).
